## 1.3 Objetivos

### 1.3.1 Objetivo general

Desarrollar un sistema de información web que permita gestionar de forma integrada el censo de familias afectadas, la ocupación de albergues, el inventario y la entrega de ayudas humanitarias y la identificación de voluntarios durante una emergencia municipal, con trazabilidad de cada operación y control de acceso por roles.

### 1.3.2 Objetivos específicos

> • **Analizar** el proceso actual de atención humanitaria municipal (censo, albergues, ayudas) e identificar sus requisitos funcionales y no funcionales.
>
> • **Diseñar** el modelo de datos y la arquitectura del sistema, garantizando la unicidad del registro de personas y la integridad del inventario.
>
> • **Implementar** los módulos de censo, albergues, inventario, entrega de ayudas y voluntarios, con registro del responsable de cada operación.
>
> • **Generar** reportes de ocupación, entregas y existencias para las autoridades municipales y departamentales.
>
> • **Validar** el sistema mediante pruebas funcionales y de aceptación con escenarios basados en emergencias reales.
